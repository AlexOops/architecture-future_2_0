# Task2 — Домены и потоки данных

## Цель

Разделить систему «Будущее 2.0» на домены, чтобы медицинское, финтех-, ИИ- и партнёрское направления могли развиваться независимо без добавления новой бизнес-логики в DWH.

## Что подготовлено

- DFD по целевым потокам данных между доменами.
- Обоснование доменной декомпозиции.
- Анализ потоков данных для ключевых бизнес-сценариев.

## Основная идея

DWH больше не является центром бизнес-логики.

Каждый домен владеет своей моделью, процессами и данными:

- Clinical Domain — клиники и медицинские процессы;
- Fintech Domain — банковские и финансовые продукты;
- AI Domain — ИИ-сервисы для медицинских сценариев;
- Partner Domain — фармацевтика, электроника и будущие партнёры;
- Corporate Domain — персонал, инвентаризация, финансы компании;
- Data Platform Domain — аналитика, витрины, каталог, lineage и semantic layer.

Домены обмениваются данными через API, события и data products. Аналитика строится на подготовленных витринах и semantic layer, а не на прямом доступе к legacy DWH.
